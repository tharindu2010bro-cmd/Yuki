Install it

  1. Open the downloaded .apk file from your notifications or the Downloads app.
  2. If Android asks, allow Install unknown apps for Chrome (or the app you downloaded with).
  3. Tap Install. If Play Protect warns you, choose Install anyway.

If Android says App not installed, the new APK was signed with a different key than the one on your phone. In the old app use Settings → Save Backup (.json), uninstall it, install the new APK, then import the backup.
